# BigInt — домашка к лекции «1-int»

Реализуй **упрощённый аналог `PyLong` из CPython** — целое произвольной
точности. Ты напишешь свой собственный `int`, который умеет складывать,
вычитать, умножать и сравнивать числа любой длины: от `0` до чисел
с сотнями десятичных разрядов.

Это та самая «реализация X в упрощённом виде» из вводной лекции:
настоящий `int` в CPython устроен именно так — см. `Objects/longobject.c`.

---

## Устройство числа (как в CPython)

Число хранится в виде массива «цифр» (limbs) по основанию `BASE`,
little-endian, знак — отдельно:

```
value = sign * sum(digits[i] * BASE**i for i in range(len(digits)))
```

| Константа | Значение      | Аналог в CPython |
|-----------|---------------|------------------|
| `SHIFT`   | `30`          | `PyLong_SHIFT`   |
| `BASE`    | `2 ** 30`     | `PyLong_BASE`    |
| `MASK`    | `BASE - 1`    | `PyLong_MASK`    |

Инварианты представления (нарушать нельзя — на них завязаны тесты):

- `0 <= digits[i] <= MASK` для всех `i`;
- `digits[-1] != 0` для ненулевых чисел (нормализованность);
- `sign`: `0` — ноль, `1` — положительное, `-1` — отрицательное.

## Что нужно реализовать

В [`bigint/bigint.py`](bigint/bigint.py) реализуй:

| Сигнатура                            | Что делает                                             |
|--------------------------------------|--------------------------------------------------------|
| `BigInt.from_string(value, base=10)` | Разбор строки: основания `2, 8, 10, 16`, знак `+`/`-`, префиксы `0b`/`0o`/`0x`, `_` между цифрами |
| `BigInt.to_string(base=10)`          | Строковое представление (без префикса, с ведущим `-`) |
| `neg(a)`                             | `-a`                                                   |
| `add(a, b)`                          | `a + b`                                                |
| `sub(a, b)`                          | `a - b`                                                |
| `mul(a, b)`                          | `a * b`                                                |
| `compare(a, b)`                      | `-1`, `0` или `1`: `a < b`, `a == b`, `a > b`          |

Каркас уже дан и **переделывать его не нужно**: `__init__`, `_normalize`,
`from_int`, `to_int`, `__repr__`. Он задаёт единое внутреннее представление,
чтобы твоя реализация армӣтики совпадала с ожиданиями тестов.

---

## Уровни сложности (как в лекции)

- **Junior**: `from_string`/`to_string` в десятичной системе счисления.
- **Middle**: `add`, `sub`, `mul`, `compare` с учётом знака; числа,
  не помещающиеся в `sys.maxsize` (твой `int` обязан с ними работать).
- **Senior**: основания `2/8/16`, префиксы `0x`/`0o`/`0b` и `_` между цифрами
  (как в литералах из лекции: `0xa_0`, `1_60`).

## Запрещено

- Использовать встроенный `int` (в т.ч. `int(s, base)`), `bin()`, `oct()`,
  `hex()`, `str()` внутри реализации арифметики, разбора и печати.
  (`from_int`/`to_int` в каркасе — единственное легальное место.)
- Менять публичные сигнатуры и внутреннее представление.

## Подсказки

- Сложение и вычитание — как «в столбик», с переносом (`carry`) и займом
  (`borrow`).
- Умножение — школьный алгоритм за `O(n·m)` с накоплением результата
  и переносом (быстрее всех изобретать не нужно, но можно попробовать
  Karatsuba как бонус).
- Печать в другую систему счисления — повторяй `divmod(x, base)`, остатки
  будут цифрами от младшей к старшей.
- Разбор строки — классический приём: для каждой цифры `d`:
  `value = value * base + d`. Префикс `0x`/`0o`/`0b` срезается заранее.
- `_` валиден только **между** цифрами (`1_000`, но не `_1`, `1_`, `1__0`).
- Для отрицательных чисел удобно работать с модулем, а знак применять в конце.

---

## Критерии приёмки

1. `make test` — все тесты зелёные.
2. Код аккуратный, с аннотациями типов, без обходов встроенным `int`.
3. Умение объяснить: почему `digits` хранятся little-endian и зачем нужен
   `MASK`, когда `carry`/`borrow` могут выходить за пределы разряда.
