# PDF-версии лекций

Здесь лежат PDF, сгенерированные из Keynote-файлов из `lectures/`
(экспорт через Keynote), чтобы содержимое слайдов было удобно читать.

Имена соответствуют исходным презентациям: `1-int.pdf` == `lectures/1-int.key`.

Это служебная папка: если какой-то PDF устарел, перегенерируй его из
соответствующего `.key` (Keynote → File → Export To → PDF).
